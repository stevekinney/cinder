# Changesets

This directory tracks pending releases for the four public packages. Run `bun x changeset` to add a new changeset describing your change. The release workflow (`.github/workflows/release.yaml`) consumes accumulated changesets to open a "Version Packages" pull request and publishes the changed public packages to npm through Trusted Publishing when that pull request is merged.

The public packages are `@lostgradient/markdown` (`packages/markdown/`), `@lostgradient/cinder` (`packages/components/`), `@lostgradient/editor` (`packages/editor/`), and `@lostgradient/cinder-mcp` (`packages/mcp/`). `@lostgradient/chat` stopped publishing on 2026-10-14; do not add changesets for it. The other workspaces remain private. Because public packages declare some of them as `workspace:*` development dependencies and bundle their output, Changesets cannot ignore those connected workspaces. Instead, `privatePackages.version: true` lets Changesets update their internal versions without publishing them.

The public packages are pre-1.0, so breaking changes use a `minor` changeset rather than `major`. Editor declares Cinder and Markdown as ordinary peer ranges so the source workspace stays resolvable against the versions currently on `main`. The `changeset:version` command prepares any dependent release Changesets needs, runs `changeset version`, and then reconciles those peer ranges to the generated Cinder and Markdown versions. After it resets the generated sources, it also rewrites the `VERSION` that `@lostgradient/cinder` exports (`packages/components/src/tokens/runtime/package-version.generated.ts`) to the bumped manifest version, so the Version Packages pull request passes `mirror-verify.yaml`'s version-constant check without a mirror sync in between. `bumpVersionsWithWorkspaceProtocolOnly: true` remains intentional: actual internal workspace links use `workspace:*`, while the ordinary peer ranges are owned by that explicit release transformation. Without the setting, Changesets promotes pre-1.0 dependents to a `major` release whenever an internal minor leaves their current peer range.

See [`config.json`](./config.json) for the full configuration. The [official Changesets docs](https://github.com/changesets/changesets) cover the workflow in depth.
