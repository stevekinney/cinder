Close the runtime coverage ratchet's remaining gap and wire it into CI (unit-tests.yaml and main-green.yaml now run `test:coverage` for this package alongside Chat's). No public API changes. Two branches this effort first called Bun coverage artifacts turned out to be genuinely untested instead: `waitForTransitionCompletion`'s SSR/no-`requestAnimationFrame` fallback (unchanged from its original shape, now covered by a real test) and `collectComposedElements`'s shadow-slot walk (also unchanged from its original shape, now covered by a test for the empty-slot native-fallback case it already handled correctly but nothing exercised). The other two are provably unreachable edges, each closed by restructuring around the unreachable edge with the proof stated in place, not a coverage-suppression comment: `composedFocusScopes`'s loop now tracks its own exit condition in a flag, since every root node an `Element` anchor's `getRootNode()` chain can produce always satisfies the loop's other condition, so that condition can never be the one that ends the loop; `splitScopeOutsideContext`'s dead ternary arm is collapsed onto its own guard clause, since `normalizeScopeRelativeSelector`'s mandatory preprocessing rules that shape out before this function ever runs. Separately, `evaluateContainerSizeConstraints`'s compound width+inline-size recursive branch is marked in place with a `cinder-coverage-unreachable` source comment (a from-source proof rather than a restructure, since every validated call path already splits that condition before this function ever sees it), and the internal `chart-utilities.ts` barrel now also re-exports `createHorizontalCategoryLabelLayout` alongside the chart helpers it already exposed.
