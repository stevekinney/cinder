Close the runtime coverage ratchet's remaining gap and wire it into CI (unit-tests.yaml and main-green.yaml now run `test:coverage` for this package alongside Chat's). No public API changes. Two branches this effort first called Bun coverage artifacts turned out to be genuinely untested instead: `waitForTransitionCompletion`'s SSR/no-`requestAnimationFrame` fallback (unchanged from its original shape, now covered by a real test) and `collectComposedElements`'s shadow-slot walk (also unchanged from its original shape, now covered by a test for the empty-slot native-fallback case it already handled correctly but nothing exercised). One is a genuinely provably unreachable edge closed by restructuring, not a coverage-suppression comment: `composedFocusScopes`'s loop now tracks its own exit condition in a flag, since every root node an `Element` anchor's `getRootNode()` chain can produce always satisfies the loop's other condition, so that condition can never be the one that ends the loop. The remaining two provably unreachable edges are each marked in place with a `cinder-coverage-unreachable` source comment rather than claimed closed by restructuring alone, because the line in question is already reached (just never taken) and Bun's line-level LCOV records it as hit regardless — a restructure by itself only relocates that same granularity gap, it doesn't close it: `splitScopeOutsideContext`'s `before`-empty guard is split onto its own line and marked, since `normalizeScopeRelativeSelector`'s mandatory preprocessing rewrites any selector-list item that would produce an empty `before` before this function ever runs; `evaluateContainerSizeConstraints`'s compound width+inline-size recursive branch is marked the same way, since every validated call path already splits that condition before this function ever sees it. The internal `chart-utilities.ts` barrel now also re-exports `createHorizontalCategoryLabelLayout` alongside the chart helpers it already exposed.
