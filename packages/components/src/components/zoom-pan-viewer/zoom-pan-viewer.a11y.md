# ZoomPanViewer design and accessibility review

Reviewer: Codex implementation review. Outcome: approved for implementation review. Nearest neighbours: Image, Carousel, CodeBlock. It owns pointer-anchored transforms and a keyboard/control model while remaining agnostic to rendered content. The viewer is focusable with an accessible label; Zoom in, Reset zoom, and Zoom out controls have explicit names; keyboard equivalents are `+`, `-`, and `0`.
